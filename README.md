# meotest
# Random Task Generator

Графическое приложение на Python (Tkinter) для случайной генерации задач по категориям.

## 👤 Автор

[Брусенцев Вячеслав Максимович]

## 🚀 Функции

- ✅ Генерация случайной задачи (кнопка)
- ✅ Категории: учёба, спорт, работа
- ✅ Добавление своих задач
- ✅ История сгенерированных задач (список)
- ✅ Фильтрация по категории и поиск по тексту
- ✅ Сохранение истории в JSON и загрузка
- ✅ Валидация: задача не может быть пустой
- ✅ Библиотека random для случайного выбора
- ✅ Тесты (pytest): позитивные и негативные случаи

## 📦 Запуск

```bash
python main.py
